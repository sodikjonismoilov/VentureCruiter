These chart fonts are static 400 and 600 weight instances of the existing
`@fontsource-variable/inter` package's `inter-latin-wght-normal.woff2`, converted
with fontTools. The bundled SIL Open Font License applies. They are derived from
the same Inter family already used by Cypher, with no runtime font downloads.

PNG text uses this Latin subset. SVG exports retain original Unicode text and
use the viewer's available fonts; full source labels also remain in the CSV.
